# ターミナル

[English](../terminals.md)

## ターミナルは動き続ける

各ターミナルの画面とスクロールバックは Iwato 自身が持つので、ブラウザを閉じても、スマホから開き直しても続きから見られます。ターミナルのプロセスは、標準イメージに入っている Iwato の小さなデーモン `iwato-entrypoint` (サンドボックスの最初のプロセス。ファイルの SFTP も出します) が持ちます。そのため:

- Iwato を再起動・更新しても、メインも追加のターミナルも終わりません。開き直すと、直前の出力 (1 MiB まで) から画面が戻ります
- メインのシェルを `exit` で終えても終わるのはそのターミナルだけで、次に開くと新しいシェルが始まります
- ターミナルの上の「＋」(「新しいターミナル」) でターミナルを増やせます
- デーモンのないイメージのサンドボックスでは、追加のターミナルは Iwato の終了で終わります
- イメージのデーモンが Iwato より古くても、使える機能はそのまま使え、残りは切り替わります (ファイルとエディタは作業ディレクトリを見せます)。作り直すと新しいデーモンになります

スマホで画面のキーボードが開いても、ターミナルの行数は変えません (履歴に同じ行が二重に出ないように)。キーの列には Esc、Tab、⇧Tab、Ctrl、矢印キーと「画像」があります。

## リンクとテキスト

- 「リンク」(「⋯」のメニュー) は、ターミナルの履歴に出た URL を新しい順に並べます。タップしたときだけ、新しいタブで開きます
- 「テキスト」(「⋯」のメニュー) は、履歴をただのテキストで出します。OS の選択 (スマホは長押し) か「全部コピー」でコピーできます
- サンドボックスのプログラムは、ブラウザの新しいタブで URL を開けます: 標準イメージはターミナルに `BROWSER=iwato-browser` を設定します。http(s) の URL だけ、見ているサンドボックスだけ、自分で入力してから数秒以内だけです
- プログラムはクリップボードにも書き込めます (OSC 52)。自分で入力した直後だけです

## 画像の貼り付け

ターミナルに画像を貼り付ける (スクリーンショットなど、テキストのない貼り付け) かドロップすると、Iwato がサンドボックスのホームの `.cache/iwato/paste/` に保存し、そのパスを貼り付けます。Claude Code は貼り付けられた画像のパスを画像として受け取ります (手元のターミナルにファイルをドロップしたときと同じ)。スマホはキーの列の「画像」で選びます。

- PNG・JPEG・GIF・WebP、20 MB まで
- 最新の 50 個 (7 日以内) だけ残します
- クリップボードにテキストもあるとき (表計算のセルなど) は、テキストだけを貼り付けます

## 通知

端末ごとに、サイドバーの「通知を有効化」でプッシュ通知を有効にします。Iwato は次のときに送ります:

- エージェントの通信の提案 (1 分以内に続いたものは 1 つにまとめます)
- ターミナルの画面が 1 分変わらなくなったとき (エージェントが作業を終えたときなど)。使うのをやめた時点の画面から変わったものだけで、見ている間の描き直しでは送りません

Slack と同じく、どの端末でも Iwato を使っていない (表示していて 5 分以内に操作した画面がない) ときだけ送ります。使っている間は、承認待ちの件数を画面のタイトルに、止まったターミナルをサイドバーとターミナルのタブの印に出します。

プッシュ通知にはセキュアコンテキストが要ります: PC では `http://127.0.0.1`、スマホでは Tailscale を通した HTTPS のアドレスです ([スマホから使う](publishing.md))。

## ターミナルの記録

画面が崩れたときにあとで調べられるよう、`iwato.json` に `"termTrace": true` を書くと、各ターミナルが開いたときから出力を記録します。記録はサンドボックスの中の `~/.local/state/iwato/term-trace/<サンドボックス>-<ターミナル>-<日時>.jsonl` (0600。ホームなので残ります) に書きます。ホストには置きません。

- 1 行が 1 件の JSON で、`h` (最初の行。サイズ)、`o` (出力。`d` は base64)、`r` (サイズの変更)、`e` (終わり。理由)。`t` は最初の行からのミリ秒です
- 記録するのは出力とサイズだけで、入力は記録しません。ただし出力は、画面に出たもの (トークンやソースコードなど) をそのまま含みます
- 1 ファイル 64 MiB で止まります (`e` の `why` が `limit`)。14 日より古いファイルは、次の記録の開始時に消します
- サンドボックスへの書き込みが遅れると、記録だけをやめてターミナルは続けます。記録を始められないときも、ターミナルは開きます (理由はログに出ます)
- 記録を始める前に起きた崩れは調べられません。サイズの変更の位置は、画面に反映された位置と出力数件ぶんずれることがあります
- 記録を再生するには、このリポジトリで `go run ./cmd/term-replay [-at ミリ秒] [-hist] FILE` を実行します (サンドボックスの中でも)。Iwato と同じエミュレーター (`internal/screen`) に記録を流し、代替画面に入った・出た時刻、サイズの変更、最後の画面を出します。同じ崩れが出れば原因はエミュレーター、出なければフレームの送り方かブラウザの描画です
