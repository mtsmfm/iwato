# 困ったとき

[English](../troubleshooting.md)

まずは「設定」の「起動時の確認」(WSLc かエンジンと設定。それぞれ直し方つき) とログを見ます: サイドバーの「ログ」か、設定フォルダーの `iwato.log` です。`serve -verbose` を付けると、ログをすべてコンソールにも出します。

## Iwato が起動しない

- **WSLc を実行できない** (画面に出て、使えるようになるまで待ちます): Windows 11 に WSL 3.0.1 以上を入れ (`wsl --update`。安定版が古いときは `wsl --update --pre-release`)、`wslc.exe --version` が動くことを確かめます。`wslc.exe` が `PATH` にないときは、Iwato を止めて `iwato.json` の `"wslc"` にフルパスを書き、起動し直します
- **ポートが使用中**: Iwato は 17600 から 17669 までを試します。`-listen 127.0.0.1:PORT` で指定できます
- **イメージやゲートウェイの準備に失敗した**: コンソールとログに理由が出ます。イメージの取得とビルドは `image-build.log` です。ghcr.io (自分でビルドした exe では github.com、Docker Hub、Ubuntu のパッケージのアーカイブも) への通信を確かめ、Iwato を起動し直します

## ログイン

- **URL が使用済み・期限切れ**: 起動時の URL は 10 分以内・1 回限りです。ログイン済みのブラウザーから「別端末でログイン」を使うか、Iwato を再起動して新しい URL を出します
- **しばらくするとログインが切れる**: セッションは既定で 8 時間です (`-session-hours`、720 まで)

## サンドボックスの中の通信

- **コマンドが 403、`policy_denied`、プロキシのエラー、接続のリセットで失敗する**: ポリシーが拒否しています。「ポリシー」タブで提案を承認するか、規則を追加します。検査する宛先で止められたメソッドやパスは提案になりません。承認一覧の規則の下に、止められたリクエストが出ます
- **承認が ambiguity のエラーで失敗する**: OpenShell は、同じホスト・ポート・パスで検査の設定が違う規則を受け付けません。ダイアログに、どの規則とぶつかるかと直し方が出ます
- **作り直したプログラムが「binary integrity」で拒否される**: OpenShell は、プログラムが最初に通信したときにハッシュを固定します。同じパスで中身が変わったプログラムは、サンドボックスを再起動するまで拒否されます。版ごとに別のパスにビルドします (サンドボックスの `/AGENTS.md` がエージェントに説明しています)

## プロバイダー

- **変数がない・古いまま**: 動いているサンドボックスでの付け外しは再起動で反映されます (「再起動待ち」)。その前に起動したプログラムには変化がありません
- **Atlassian や xAI の許可が切れた**: 「プロバイダー」で「再接続」し、付けているサンドボックスを再起動します

## ターミナルとファイル

- **Iwato を更新したらターミナルが戻らない**: Iwato のデーモンのないイメージのサンドボックスでは、追加のターミナルは Iwato の終了で終わります。標準イメージで作り直します ([サンドボックスとイメージ](sandboxes.md))
- **ファイルやエディタにホームでなく `/sandbox` が出る (「作業ディレクトリ (/sandbox) を開きます。」)**: Iwato のデーモンのないイメージか、デーモンが Iwato より古いイメージで作ったサンドボックスです。標準イメージで作り直します
- **ターミナルの画面が崩れる**: ターミナルの記録を有効にして再生します ([ターミナル](terminals.md))
- **Windows で大きなファイルをドライブにコピーできない**: Windows の WebDAV のクライアントは、既定では約 48 MB までです

## 公開したポート

- **ツールが `5173.dev.localhost` を解決できない**: ブラウザーは `*.localhost` を自分で解決しますが、ほかのプログラムはしないことがあります。`curl --resolve 5173.dev.localhost:17600:127.0.0.1 …` を使います
- **502**: サンドボックスでそのポートを待ち受けているものがありません (または loopback やすべてのアドレス以外の、特定のアドレスだけで待ち受けています)
- **503**: サンドボックスが停止中か、同時の接続が多すぎます
- **Vite が「Blocked request. This host is not allowed」と出す**: 既定の `host` の設定では出ないはずです。`iwato.json` のそのポートの `host` を確かめます ([ポートの公開](publishing.md))
- **Tailscale のノードがない・重複する (`-1`)**: ログの `logout:` の行を見て、古いノードを Tailscale の管理画面で削除します

## やり直す

「設定」の「すべて消す」で、Iwato が作ったものをすべて削除し、最初の起動と同じ状態から始めます ([設定とリセット](settings.md))。

## 問題を報告する

<https://github.com/mtsmfm/iwato/issues> に、「設定」の「起動時の確認」、`iwato version` の出力、`iwato.log` の関係する部分を添えて issue を作ってください。ログにはサンドボックス名・ホスト・パスが含まれるので、貼る前に読んでください。
