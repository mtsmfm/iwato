# ファイルとエディタ

[English](../files-and-editor.md)

どちらもサンドボックスのホーム `/home/dev` を見せます。Iwato の決まりに従わないイメージ のサンドボックスでは、代わりに OpenShell の作業ディレクトリを見せ、「作業ディレクトリ (…) を開きます。」と表示します。標準イメージで作り直すとホームになります ([サンドボックスとイメージ](sandboxes.md))。

## ファイル: ホームをネットワークドライブに

「ファイル」(カードの「⋯」のメニュー) は、ホームをネットワークドライブ (WebDAV) として Windows のエクスプローラー、macOS の Finder、スマホの WebDAV アプリで開けるようにします。変更はすぐサンドボックスに届きます。Iwato 自身はファイルを持たず、WebDAV をサンドボックスの SFTP に翻訳します。

端末ごとに「アプリパスワードと URL」で作り (値は作った直後に 1 回だけ表示します)、要らなくなったら「取り消す」で取り消します。どれも「このサンドボックスだけ」か「すべてのサンドボックス」、「読み書き」か「読み取り専用」を選べます。種類は 2 つです:

- **「この PC 用の URL」** (Windows): エクスプローラーのアドレス欄か「ネットワークドライブの割り当て」に貼る秘密のパス `\\127.0.0.1@…`。パスワードは聞かれません (URL が鍵です)。この PC (127.0.0.1) からしか使えません。共有しないでください
- **「アプリパスワード」**: Iwato を `-public-origin` 付きで動かしているとき ([スマホから使う](publishing.md))、tailnet の HTTPS で Windows・Mac・スマホから使います。Iwato を動かしている Mac では `http://127.0.0.1:PORT/dav/NAME/` でも使えます。ユーザー名はアプリパスワードの ID、パスワードはその値です。タブに URL と手順が出ます:
  - Windows: エクスプローラーで「PC」を右クリックし「ネットワークドライブの割り当て」、URL を貼り、「別の資格情報を使用して接続する」に✓
  - Mac: Finder で ⌘K (移動 → サーバへ接続)、URL を貼り、ID とパスワードを入れる
  - スマホ: WebDAV のアプリ (iPhone: Documents、FE File Explorer など。Android: Material Files、Solid Explorer など)。スマホが tailnet に参加していること。iPhone の「ファイル」の「サーバへ接続」は WebDAV に対応していません

注意:

- Windows の WebDAV のクライアントは、既定では約 48 MB より大きいファイルを扱えません。初めての接続に 20 秒ほどかかるときは、インターネットオプションの「設定を自動的に検出する」を外すと速くなります
- Finder が `._*` や `.DS_Store` を書かないようにするには、Mac で `defaults write com.apple.desktopservices DSDontWriteNetworkStores -bool true` を実行します
- サンドボックスが停止中のときは、ドライブに `停止中です.txt` だけが見え、書き込めません

## エディタ

「エディタ」タブで、ホームのテキストファイルをその場で開いて直し、保存できます (ドライブを VS Code などで開くほどでもないときに)。

- タブで複数のファイルを開けます。未保存のファイルには印が付きます
- 幅の広い画面では、タブの並びの「並べて表示」ボタンで、左にエディタ、右にターミナルを並べられます。間の線をドラッグして幅を変え、クリックした側にキー入力が入ります。「ポリシー」「ポート」タブや ⋯ の画面はその場所に出て、「ターミナル」か「エディタ」に戻ると並びに戻ります。このブラウザが覚えます。ウィンドウを狭めるとタブの表示に戻ります
- Ctrl+P (Mac は ⌘P) でファイル名の一部を入れて開きます (VS Code のクイックオープンと同じあいまい検索。隠しパスは `.` から入れない限り後ろに並びます)。↑↓ と Enter、Esc で閉じます。Ctrl+S (⌘S) で保存します。スマホは「ファイルを開く」「保存」のボタンで
- 「フォルダー」で、探す範囲をホームの下のフォルダーに絞れます (例: `work/iwato`。最初は `~/work` があればそこ)。サンドボックスごとにこのブラウザが覚えます
- そのフォルダーのツリーを PC では左に (「ツリー」で出し入れ)、スマホは引き出しに出します。フォルダーは開いたときに読み (2,000 個まで。「更新」で読み直す)、開いたフォルダーを覚え、開いているファイルに印を付けます。隠しファイルも出し、`node_modules` などの重いフォルダーは自動では開きません。シンボリックリンクには印を付け、ファイルへのリンクだけ開けます
- ファイルの一覧は、サンドボックスの中でサンドボックスのユーザーとして `rg --files --hidden` を実行して作ります (`.gitignore` に従い、`.git`・`node_modules`・`.cache` などは除く。50,000 個まで、30 秒キャッシュ。「一覧を更新」で読み直す)。`rg` のないイメージでは SFTP でたどります
- 開けるのは 5 MB までの UTF-8 のテキストと、ブラウザが表示できる 20 MB までの画像 (PNG・JPEG・GIF・WebP・AVIF・SVG・BMP・ICO。中身で判定) です。画像は表示だけで、名前・大きさ (px)・サイズを出し、クリックで表示欄に収めるか 100 % かを切り替え、「再読み込み」で読み直します。SVG は「テキストで開く」でテキストとしても開けます。そのほかのバイナリは開きません
- 保存は一時ファイルに書いてから置き換えます (権限はそのまま)。開いた後にほかで変更されていれば保存を止め、「読み込み直す」か「上書き保存」を選べます
- ファイル名で言語を判断して色分けします: JavaScript・TypeScript (JSX・TSX)・JSON・HTML (SVG・XML も)・CSS・Markdown・Python・Go・Rust・YAML・シェルスクリプト・Dockerfile・SQL・Ruby・TOML。そのほかはプレーンテキストです。行番号、括弧の対応、折りたたみがあり、元に戻す (Undo) の履歴はファイルごとに残ります。Tab で字下げ (Go と Makefile はタブ、ほかは空白 2 つ。複数行を選んでいればまとめて)、Shift+Tab でテキストから出ます。Enter は字下げを引き継ぎます
- Ctrl+F (⌘F) でファイルの中を検索・置換します (大文字と小文字の区別、正規表現、単語単位)。Ctrl+G (⌘G) か F3 で次を探し、Ctrl+Alt+G (⌘⌥G) で行へ移動します。補完はありません
